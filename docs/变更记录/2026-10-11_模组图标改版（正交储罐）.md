# 模组图标改版（正交储罐）

日期：2026-10-11
依据：机主要求——图标改为「前景是储罐方块的正交视图，用经验流体的某一帧做背景」

## 改了什么
- `src/main/resources/waystone_xp_payment.png`：重画。前景＝储罐方块，按正视 + 顶面 + 右侧面的正交（dimetric）立方体呈现，配色取自方块贴图 `assets/waystone_xp_payment/textures/block/xp_payment_tank.png`；背景＝ Create: Enchantment Industry 的 `assets/create_enchantment_industry/textures/fluid/experience_still.png` 第 0 帧（16×16），2 倍放大后 2×2 平铺铺满，整体暗化 0.70 再叠径向暗角。
- `tools/make_icon.mjs`：重写。新增内嵌常量 `FLUID_B64`（那一帧的 16×16 RGBA，解码后必须为 1024 字节），生成器因此不再需要任何外部输入；新增扫描线填充 `quad()` 与 `hline/vline/dline` 三个画线原语来搭立方体；输出仍是 64×64 逻辑网格最近邻 ×4 = 256×256，无第三方依赖（`node:zlib` + 自写 PNG 编码器）。
- 上一版（石碑 + 储罐 + 经验球，4,715 B，sha256 `faeb74a0…`）作废；`docs/变更记录/2026-10-11_模组图标.md` 记的是那一版，以本篇为准。

## 为什么改
- 机主看过上一版后要求改版：前景要「储罐方块的正交视图」，背景要「经验流体的某一帧」。
- 旧版把石碑与储罐竖排堆叠，视觉重点落在石碑上，而不是本模组特有的储罐；流体背景能一眼说明「用经验流体扣费」这个主题。

## 根因分析
- 新版生成器第一次跑出来的是坏 PNG：`IHDR` 按 256×256 写，像素数据却只有 64×64（`read_image` 报 `Unsupported or malformed image data`，GDI+ 也报 `Save(...) 中发生一般性错误`）。原因是重写时漏掉了最近邻放大那一步——编码阶段用 `N * S` 当行宽，而缓冲区还是 `N` 的逻辑网格。
- 修法：先按 S 倍最近邻把逻辑网格放大成 `W = N * S` 的输出缓冲，再按 `W` 逐行编码；新增 `D:\deepseek\.tmp\pngcheck.mjs` 做校验，确认 `inflate` 后长度 == `W * (W * 4 + 1)` 且每行过滤器字节为 0。

## 自定夺（与规格不一致或规格未写）
- 背景取第 0 帧：该 `.mcmeta` 声明 20 帧、`frametime: 2`、序列为 0..19 再 18..1，第 0 帧是动画起点，最能代表这条流体。内嵌的是**该帧的原始像素**，流体纹理换版本后图标不会自动更新，需要重新导出并替换常量。
- 流体帧数据内嵌进生成器而不另存文件：保持「一个脚本 + 一条命令」即可复现，同时不把第三方模组的纹理单独收进本仓库。
- 罐内窗口继续用本模组贴图的绿 `#56D67C`（而非流体的黄绿），避免前景与背景混成一片。
