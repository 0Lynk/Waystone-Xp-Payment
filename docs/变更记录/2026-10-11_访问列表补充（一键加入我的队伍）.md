# 2026-10-11 访问列表补充：一键加入自己的队伍

## 改了什么
- 客户端 `XpPaymentTankScreen` 新增第三个头部按钮 `+ 添加我的队伍`（en: `+ Add teams`）：一次把自己当前所在的、
  尚未出现在列表里的队伍全部加入。头部三按钮改为 Mode 84px @x=8、`+ 添加我` 72px @x=100、`+ 添加我的队伍`
  72px @x=180，右边缘 252（面板宽 256），仍与流体条、列表对齐。
- 该按钮在自己没有任何队伍、或自己的队伍都已在列表里时置灰（`listedAsTeam()` 判定），避免点了没反应。
- 新增语言键 `access.add_team`（en/zh）；README 的“在游戏内”一节改为描述新的列表界面。

## 为什么
上一版把权限界面做成了可点列表，但只能加入“我”这一个玩家：队伍只能删、不能加。需求里的“增加/删除/修改”
对队伍同样成立。服务端 `XppServerHandler.addOwnTeam` 本来就只接受“发送者自己在的队伍”，所以客户端只要把这些
队伍发出去即可，不需要新的权限模型，也不需要自造队伍标识——队伍身份仍然是 FTB Teams 的 `Team.getId()`。

## 取舍
- 一个按钮批量加入，而不是每支队一个按钮：队伍数量不定，批量更简单；代价是玩家无法只挑一队加入（可以先加入
  全部，再删掉不要的那条）。
- 复用既有 `XppStatePayload.ownTeams`（服务端本来就在发），没有新增网络包，也无需新字段。
- `id == null` 的队伍项一律视为“已列出/不可添加”，因为按 UUID 寻址是这套协议的硬前提。
